# IT-GIRL-WEB
Die Webseite für junge Frauen und Studentinnen in Zürich: Eine interaktive Karte zeigt Bibliotheken, Cafés und mehr, mit Links zu Google Maps oder zur Website des Ortes. Plane deinen Tag mit Orten von der Karte, lies wichtige Weltnachrichten für Frauen und finde Tipps zu Lerntechniken, Notizen, Podcasts und Creators.
